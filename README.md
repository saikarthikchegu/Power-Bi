# 📊 Power BI Financial Dashboard

An interactive, end-to-end business intelligence solution designed to track, analyze, and visualize core financial performance metrics. This project demonstrates modern data modeling, ETL data preparation via Power Query, and advanced DAX measures to drive data-backed financial decisions.

---

## 🚀 Project Overview

Financial tracking and profitability analysis are critical for sustainable business growth. This Power BI report transforms raw transactional data into dynamic visual insights, enabling stakeholders to monitor revenue streams, operational expenses, profit margins, and variance trends at a glance.

---

## 🛠️ Key Features & Capabilities

* **Executive Summary / KPI Cards:** High-level tracking of Total Revenue, Total Expenses, Net Profit, and Profit Margins.
* **Trend Analysis:** Interactive time-series charts mapping financial growth, seasonal spikes, and expense fluctuations across months and quarters.
* **Profitability Breakdown:** Detailed views analyzing profitability by category, product, region, or department.
* **Dynamic Filtering:** Slicers allowing users to filter data dynamically by fiscal year, region, business unit, and category.

---

## 📈 Technical Implementation

* **Data Modeling:** Built using a structured star schema to optimize report performance and relationship management.
* **ETL (Power Query):** Data cleaning, transformation, unpivoting, and handling missing values to ensure data integrity before reporting.
* **Advanced DAX Measures:** Custom calculations built for time-intelligence functions (Year-to-Date, Same Period Last Year), ratio analysis, and conditional formatting.
